# QCMBuilder

QCMBuilder is a web app designed for educators to create and export QCM(Multiple Choice Question) tests effortlessly. Teachers can build tests by adding questions step by step and organize them as needed. Once completed, tests can be exported in multiple formats, including PDF for printing, web for online access, or SCORM for LMS integration. The app provides a user-friendly interface, making test creation and management straightforward. With QCMBuilder, educators save time and ensure tests are accessible across various platforms.

Stay tuned for updates and new features as I continue improving QCMBuilder to simplify test generation !
